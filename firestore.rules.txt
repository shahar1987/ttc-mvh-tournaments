כלל ההרשאה לאפליקציית התחרויות
================================
מקור האמת של כללי האבטחה הוא הקובץ firestore.rules במאגר של אפליקציית
הנוכחות (ttc-mvh-attendance). הכלל למטה כבר נמצא שם, בתוך הבלוק
match /databases/{database}/documents { ... }.
הקובץ הזה הוא רק עותק לבדיקה — אין להדביק בלוק match /tournaments נוסף.

אם השמירה בענן נכשלת, כנראה שהקובץ העדכני עוד לא פורסם.
בקונסולת Firebase של הפרויקט ttcmh-2a752:
Firestore Database  ⟵  לשונית Rules
לוודא שהכלל הזה מופיע שם פעם אחת בדיוק. אם לא — לפרסם את הקובץ
firestore.rules כולו מהמאגר של אפליקציית הנוכחות, ואז Publish.


    match /tournaments/{id} {
      allow read: if hasProfile();
      allow create, update: if canCompete()
        && request.resource.data.get('state', '') is string;
      allow delete: if hasPerm('competitions');
    }


המשמעות: כל מי שרשום במועדון (יש לו מסמך באוסף users) יכול לקרוא
תחרויות. ליצור ולעדכן — רק מי שיש לו גישה לתחרויות: מנהל, מי שקיבל הרשאת
"תחרויות ודירוג", או מאמן/צופה שעוד לא נקבעו לו הרשאות פרטניות (ברירת
המחדל של התפקיד). מחיקה — רק למנהל או למי שיש לו הרשאת "תחרויות".
משתמש מחובר שאינו רשום במועדון, ומשתמש לא מחובר, לא יכולים לגעת בכלום.

hasProfile(), hasPerm() ו-canCompete() הן פונקציות עזר שכבר מוגדרות בקובץ הכללים.

לבדיקה שהכל עובד: באפליקציה, לוחצים על מחוון הסנכרון בפינה העליונה.
