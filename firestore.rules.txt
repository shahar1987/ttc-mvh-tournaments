כלל ההרשאה לאפליקציית התחרויות
================================
שימו לב: מקור האמת של כללי האבטחה הוא הקובץ firestore.rules
במאגר של אפליקציית הנוכחות (ttc-mvh-attendance). הכלל למטה כבר נמצא שם.
הקובץ הזה הוא רק עותק להדבקה מהירה.

בקונסולת Firebase של הפרויקט ttcmh-2a752:
Firestore Database  ⟵  לשונית Rules

להוסיף את השורות הבאות בתוך הבלוק הקיים
match /databases/{database}/documents {  ...  }
לצד הכללים שכבר קיימים שם (אין למחוק כלום), ואז ללחוץ Publish.


    match /tournaments/{id} {
      allow read, write: if hasProfile();
    }


המשמעות: רק מי שרשום כחבר מועדון (יש לו מסמך באוסף users, כמו
באפליקציית הנוכחות) יכול לקרוא ולכתוב תחרויות. משתמש מחובר שאינו
רשום במועדון, ומשתמש לא מחובר, לא יכולים לגעת בכלום.

hasProfile() היא פונקציית עזר שכבר מוגדרת בקובץ הכללים.
אם מדביקים את הכלל לקובץ כללים אחר שאין בו אותה, צריך להחליף
את התנאי ב-request.auth != null.

לבדיקה שהכל עובד: באפליקציה, לוחצים על מחוון הסנכרון בפינה העליונה.
