# תן לי שולחן — ניהול תחרויות טניס שולחן

אפליקציית ווב של מועדון טניס שולחן מבואות החרמון לניהול תחרויות מקצה לקצה — הרשמה, הגרלה, ניהול שולחנות בזמן אמת, טבלאות ותוצאות — לפי תקנון ITTF.

כתובת חיה: **https://shahar1987.github.io/ttc-mvh-tournaments/**

## מה האפליקציה עושה

- **חמש שיטות תחרות**: בתים + נוקאאוט (ITTF מלא, כולל שוברי שוויון לפי סעיף 3.7.5), שוויצרית (שובר בוכהולץ), אמריקנו, מקסיקנו, ומלך השולחן.
- **הרשמת שחקנים** — הוספה ידנית, הדבקת רשימה מוואטסאפ, או ייבוא ישיר מאפליקציית הנוכחות של המועדון (אוסף `players` המשותף).
- **הגרלה בשיטת נחש** (snake seeding) עם הפרדת שחקני אותו מועדון בין הבתים כשאפשר.
- **ניהול שולחנות חי** — פיזור אוטומטי/ידני של משחקים לשולחנות פנויים, תור ממתינים עם סדר עדיפות (סיבוב, פיגור בית, זמן המתנה), גרירה-ושחרור.
- **הזנת תוצאות** מהירה עם מילוי אוטומטי של הצד השני, זיהוי ניצחון טכני/פרישה, וביטול (undo) של התוצאה האחרונה.
- **עץ נוקאאוט** אוטומטי מהבתים (כולל בית ניחומים ומשחק על מקום 3), עם הפרדת שחקני אותו בית/מועדון בסיבוב הראשון.
- **מסך לאולם** (TV/פרויקטור) שמתחלף אוטומטית בין שולחנות חיים / הבאים בתור / תוצאות אחרונות / טבלה.
- **פודיום וסיכום** בסיום, כולל שיתוף לוואטסאפ, ייצוא CSV וגיבוי JSON.
- **סנכרון בזמן אמת** בין מכשירים דרך Firestore, עם עבודה אופליין ושמירה מקומית כגיבוי.

## טכנולוגיה

קובץ HTML אחד בלבד (`index.html`, ~1,800 שורות) — JavaScript וניל (ללא framework/build step), CSS עם משתני עיצוב (`:root` custom properties). מצב האפליקציה כולו נשמר באובייקט גלובלי `S` ומסונכרן ל-Firestore.

שימוש באותו פרויקט Firebase של אפליקציית הנוכחות (`ttcmh-2a752`): אותם משתמשים/הרשאות (`Firebase Auth`), ייבוא שחקנים מהאוסף `players`, ושמירת התחרויות באוסף הייעודי `tournaments` (מסונכרן בזמן אמת, עם מספר גרסה `rev` ליישוב התנגשויות).

**עיצוב**: כיוון "דף המועדון הבהיר" — פלטת כחול (`#0F4C81`)/כתום (`#C2410C`) על רקע בהיר, גופנים Assistant (טקסט) ו-Heebo (כותרות ומספרים, tabular numerals), נגישות AA לפחות בכל צירופי הצבעים.

## מבנה הנתונים (אוסף `tournaments`)

```
name, date, phase, playersCount, rev, client,
state (JSON של כל מצב התחרות — שחקנים, בתים, משחקים, שולחנות, יומן),
updatedAt, updatedBy, createdBy
```

## פריסה

1. ריפו ציבורי `ttc-mvh-tournaments`, הקבצים בשורש, ענף `main` — **אין build step**, מה שמעודכן ב-`index.html` הוא בדיוק מה שמוצג באתר.
2. Settings → Pages → Source: Deploy from a branch → `main` / root.
3. ב-Firestore → Rules צריך את הכלל מתוך `firestore.rules.txt`, ואז Publish.

## קבצים בריפו

| קובץ | תפקיד |
|---|---|
| `index.html` | כל האפליקציה — HTML, CSS, JS ותצורת Firebase |
| `manifest.json` | הגדרות PWA (שם, צבעים, אייקון) |
| `icon.svg` | אייקון האפליקציה |
| `firestore.rules.txt` | כלל ההרשאות שיש להדביק בקונסולת Firebase |
